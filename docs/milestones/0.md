# Milestone 0: Controlled Test Lab

## Goal

Build local tools for testing the proxy. Start with a simple working exchange, then add ways to reproduce failures.

## Checklist

- [x] Create a Rust project with Tokio.
- [x] Build a TCP test server that listens on `127.0.0.1:9001`.
- [ ] Make the server send back every byte it receives (an echo server).
- [ ] Build a simple TCP client that connects to the server, sends a message, and prints the response.
- [ ] Verify that the response matches the message sent.
- [ ] Build a basic TCP proxy that listens on `127.0.0.1:8000` and connects to `127.0.0.1:9001`.
- [ ] Make the proxy forward bytes in both directions.
- [ ] Make the proxy print when a connection starts and ends.
- [ ] Connect the client to the proxy and verify that the echoed message returns through it.
- [ ] Make the test server runnable as three backends with distinct identities and ports.
- [ ] Add a backend response that includes its identity and echoes the request.
- [ ] Add a mode that delays response headers.
- [ ] Add a mode that sends a response body slowly, in chunks.
- [ ] Add a mode that returns a configurable error response.
- [ ] Add a mode that disconnects halfway through a response.
- [ ] Add a mode that accepts a connection but never responds.
- [ ] Extend the TCP client so it can send exact bytes, including malformed messages, with configurable delays.
- [ ] Add automated tests that demonstrate the slow, failed, and malformed interactions without external services.

## Done when

- [ ] A message travels from the client through the proxy to the echo server and back.
- [ ] Automated tests can reproduce the lab's slow, failed, and malformed interactions locally.

The basic proxy is a learning exercise. Milestone 1 adds bounded buffering, half-close handling, timeouts, graceful shutdown, counters, and a dashboard.
